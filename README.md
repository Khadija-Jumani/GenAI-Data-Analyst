# GenAI Data Analyst
### An Intelligent AI-Powered Data Analytics Platform

**Turning Raw Data into Meaningful Insights with Generative AI**

GenAI Data Analyst is an AI-powered data analytics platform designed to simplify data exploration, analysis, and interpretation through Generative AI. It combines automated Exploratory Data Analysis (EDA), interactive data visualization, and intelligent AI-driven insights to help users understand complex datasets using natural language.

The platform enables users to upload CSV and Excel datasets, explore data quality, generate statistical summaries, visualize patterns, and interact with an AI assistant to obtain meaningful explanations and data-driven insights.

The initial development phase focuses on healthcare analytics using public, de-identified datasets, with the long-term goal of supporting multiple domains, including business, finance, education, and healthcare.

---

## Project Vision

The vision of GenAI Data Analyst is to make data analytics more accessible, intelligent, and interactive by combining traditional Data Science techniques with modern Generative AI capabilities.

Instead of manually performing every analytical task, users will be able to interact with their datasets through an intelligent assistant that helps automate data exploration, understand patterns, generate visualizations, and communicate analytical findings.

- Multi-step analytical workflows.
- Tool-assisted data analysis.
